# [SC-036d] Negotiate mode Phase 4 — switch targets to localhost and auto-start px

**Status**: Open
**Priority**: High
**Component**: `lib/wsl/scripts/setup-proxy-negotiate.sh`
**Depends on**: [SC-036c](sc-036c.md)
**Parent**: [SC-036](sc-036.md)

**Summary**:
As a developer, I want all my tools (shell env, apt, Docker, Podman) pointed at `http://localhost:3128` with no credentials anywhere, and px to auto-start in interactive shells so that I reach the full Negotiate-mode state on every new shell.

**Description**:
Implements Phase 4 of the SC-036 workflow. Precondition: SC-036c verified that `curl -x http://localhost:3128` works with a Kerberos ticket. This slice rewrites all the configuration targets that were set to Basic-auth URLs in Phase 1 so they now use `http://localhost:3128` — no credentials — and adds a px auto-start block to `.bashrc` guarded by a ticket check.

After this slice the full Negotiate state is reached: no Basic-auth creds exist in any file on disk (except whatever the user already had outside the managed blocks); `/proc/*/environ` shows only `HTTP_PROXY=http://localhost:3128`; AI coding agents in the session see the localhost URL, which is useless without the Kerberos ticket.

**Scope Decisions**:
- **`.profile` for env vars, `.bashrc` for px auto-start**: env vars need to work in non-interactive login shells (`wsl.exe --exec bash -l script.sh`), so they go in `.profile` like Basic mode. px auto-start should only run in interactive dev shells (we don't want to spawn px from every scripted WSL invocation), so it goes in `.bashrc`. Matches the existing SC-007 pattern for env-var placement.
- **`klist -s` guard before starting px**: if the Kerberos ticket has expired, starting px silently leaves every request 407-ing. The bashrc block checks `klist -s` first and, if it fails, prints a friendly `Run 'kinit' to authenticate with Kerberos before using the proxy` line instead of starting px. Explicit failure is better than silent breakage.
- **Full path `~/.local/bin/px`** in the auto-start block: avoids PATH ordering issues in the very first shell after setup.
- **Marker transition**: write `negotiate` to `/etc/wsl-manager/proxy-mode` at the end of a successful Phase 4. From this point on, SC-036e's teardown treats this as a fully-migrated Negotiate install.
- **Overwrite, don't delete**: Phase 1 wrote `apt.conf.d/99proxy` with Basic-auth creds; this phase overwrites it with the localhost URL. No transient state where apt has no proxy config.

**Acceptance Criteria**:
- [ ] `.profile` managed block is rewritten: `http_proxy`/`https_proxy` (+ upper-case variants) set to `http://localhost:3128`; `no_proxy` includes `localhost,127.0.0.1` plus any user-provided additions
- [ ] `/etc/apt/apt.conf.d/99proxy` is rewritten with `http://localhost:3128` (no creds)
- [ ] `~/.docker/config.json` is rewritten with `http://localhost:3128` (no creds)
- [ ] `~/.config/containers/containers.conf` is rewritten with `http://localhost:3128` (no creds)
- [ ] `.bashrc` gains a managed `# BEGIN wsl-manager proxy` / `# END wsl-manager proxy` block (idempotent — re-run replaces, doesn't append) that:
  - [ ] Runs `klist -s` and, on failure, prints a `kinit` reminder instead of starting px
  - [ ] On success: starts `~/.local/bin/px` via `nohup` only if no px process is already running (`pgrep -x px`)
- [ ] No Basic-auth credentials exist in `.profile`, `apt.conf.d/99proxy`, Docker or Podman configs after a successful run (grep-able assertion in UAT)
- [ ] `/etc/wsl-manager/proxy-mode` contains `negotiate` after success
- [ ] Re-run: safely overwrites all managed blocks; does not duplicate bashrc content
- [ ] All existing tests continue to pass

**Technical Notes**:
- `.profile` managed block (env vars — same file and marker as Basic mode):
  ```bash
  # BEGIN wsl-manager proxy
  export HTTPS_PROXY="http://localhost:3128"
  export HTTP_PROXY="http://localhost:3128"
  export https_proxy="http://localhost:3128"
  export http_proxy="http://localhost:3128"
  export NO_PROXY="localhost,127.0.0.1"
  export no_proxy="localhost,127.0.0.1"
  # END wsl-manager proxy
  ```
- `.bashrc` managed block (px auto-start — interactive shells only):
  ```bash
  # BEGIN wsl-manager proxy
  # Start px local proxy — requires a valid Kerberos ticket
  if klist -s 2>/dev/null; then
      pgrep -x px > /dev/null || nohup ~/.local/bin/px > /dev/null 2>&1 &
  else
      echo "wsl-manager: run 'kinit' to authenticate with Kerberos before using the proxy"
  fi
  # END wsl-manager proxy
  ```
