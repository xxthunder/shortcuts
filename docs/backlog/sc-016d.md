# [SC-016d] Replace distro selection with Read-SpectreSelection

**Status**: In Progress
**Priority**: High
**Component**: `lib/wsl/commands.ps1`, `lib/wsl/commands.Tests.ps1`
**Parent**: [SC-016](sc-016.md)
**Depends on**: [SC-016a](sc-016a.md)

**Summary**:
As a user, I want to pick a distribution using arrow-key navigation so that I no longer need to type a number or name and press Enter.

**Description**:
Refactor `Select-WslDistro` and `Invoke-CreateDistro`'s inline selection to use `Read-SpectreSelection` for interactive distro picking. The CLI path (pre-provided `-Selection` or `-Name` parameter) remains unchanged for non-interactive use.

### Technical approach

- `Select-WslDistro`: when no `-Selection` is pre-provided and not in CI, use `Read-SpectreSelection` with distro names as choices. Return `$null` on Esc/cancel.
- Keep the `-Selection` parameter path unchanged for CLI and scripted use (number or name resolution)
- `Invoke-CreateDistro`: replace the `Read-Host` numbered selection (lines 167-203) with `Read-SpectreSelection` using `$availableDistros` as choices
- Update `commands.Tests.ps1`: mock `Read-SpectreSelection` for interactive paths, keep CLI path tests unchanged
- Test: cancel (Ctrl+C) returns `$null`, valid selection returns distro name

### Scope Decisions

- **Cancel is Ctrl+C, not Esc.** `Read-SpectreSelection` (PwshSpectreConsole 2.6.x) has no Esc handling; Ctrl+C cancels the prompt and returns `$null`. No synthetic "Cancel" choice is added; this matches how SC-016b resolved the same wording for `Show-WslMenu`.
- **CI/test path warns and returns `$null`.** When no selection is pre-provided and `Test-RunningInCIorTestEnvironment` is true, `Select-WslDistro` and `Invoke-CreateDistro` write a warning telling the caller to pass `-Name` and return without prompting. There is no `Read-Host` fallback; the old prompt would only hang in CI. Mirrors `Start-InteractiveMode`.
- **Number/name resolution survives only on the pre-provided path.** Interactive callers can no longer type a number or an unknown name, so the "invalid number" and "name not found" errors are reachable only via `-Selection` / `-Name` (CLI). The pre-existing `Invoke-TerminateDistro` CI throw-guard is left untouched (the epic requires action functions to stay structurally unchanged).
- **Prompt shape** matches `Show-WslMenu`: `-PageSize 15 -EnableSearch`, so long online-distro lists are searchable by typing.
- **Selection is echoed after the prompt** (UAT feedback). Spectre clears the prompt on selection and the action that follows can take a while before it prints anything, so the picker writes `==> Selected distribution: <name>` via `Write-Status` immediately after a successful pick. Applies to both `Select-WslDistro` and `Invoke-CreateDistro`; not on the CLI `-Name` path.

**Acceptance Criteria**:
- [ ] `Select-WslDistro` uses `Read-SpectreSelection` for interactive distro picking
- [ ] `Invoke-CreateDistro` uses `Read-SpectreSelection` for available distro selection
- [ ] Pressing Ctrl+C at distro selection returns to main menu (returns `$null`)
- [ ] CLI mode (`-Selection` / `-Name` provided) still works without Spectre prompts
- [ ] In CI/test with no selection provided, a warning is written and no prompt is shown
- [ ] The selected distribution name is echoed right after the prompt closes
- [ ] Updated tests with mocked `Read-SpectreSelection`
- [ ] All existing tests continue to pass
- [ ] UAT procedure below executed; all steps pass

### UAT Procedure

1. Run `tools\wsl-manager\wsl-manager.bat`, select **Remove distribution**. Expected: an arrow-key list of the installed distributions appears below the table; typing letters filters the list.
2. Press Ctrl+C in that list. Expected: a "Cancelling" warning, then "Press Enter to continue", then the main menu; nothing was removed.
3. Select **Install new distribution**. Expected: an arrow-key list of the `wsl --list --online` names; Ctrl+C cancels with a "Cancelling" warning and returns to the menu.
4. Select **Update distribution**, highlight a distribution and press Enter. Expected: `==> Selected distribution: <name>` is printed immediately, then the update runs for that distribution without any further "number or name" prompt.
5. CLI: `pwsh -File tools\wsl-manager\wsl-manager.ps1 remove <existing-name>` and `... install <online-name>`. Expected: the action runs (or its confirmation appears) with no Spectre selection prompt.
6. CLI in CI mode: `$env:CI = 1; pwsh -File tools\wsl-manager\wsl-manager.ps1 remove` (no name). Expected: a warning telling you to provide `-Name`; the command exits without hanging.
