# [SC-011] WSL Manager: mask credentials and auto-terminate after install

**Status**: Completed (2026-03-04)
**Priority**: High
**Component**: `tools/pslib/wsl/wsl-manager.ps1`

**Summary**:
As a user running wsl-manager behind a corporate proxy, I want my credentials masked in terminal output. As a user installing Docker or Podman, I want the distro terminated automatically so I don't have to do it manually.

**Description**:
Two usability and security issues found during a hands-on DevContainer walkthrough.

**Tasks**:

1. **Mask proxy credentials in output** — When `setup-proxy` is run with credentials, the environment variables are printed to the terminal with the password in plain text. All output that includes proxy URLs must mask the password portion (e.g., `http://user:****@proxy:8080`).

2. **Auto-terminate distro after Docker/Podman install** — The `install docker` and `install podman` actions require a distro restart to take effect, but currently leave it to the user. The actions should terminate the distro at the end automatically (with an informational message) so the user doesn't have to run a separate step.

**Acceptance Criteria**:
- [x] `setup-proxy` output masks the password in any proxy URL (env vars, apt config, etc.)
- [x] No plain-text password appears in terminal output during or after proxy setup
- [x] `install docker` terminates the target distro after successful installation
- [x] `install podman` terminates the target distro after successful installation
- [x] Informational message printed before termination (e.g., "Terminating <distro> to apply changes…")
- [x] Unit tests cover credential masking logic
- [x] All existing tests continue to pass
