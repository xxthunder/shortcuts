# [SC-072] Backlog index the backlog script can derive

**Status**: In Progress
**Priority**: Medium
**Component**: `docs/backlog/README.md`, `docs/backlog/sc-013.md`, `docs/backlog/sc-021.md`
**Related**: [SC-068](sc-068.md) and [SC-069](sc-069.md) (pulls that hit the problem), [SC-036b](sc-036b.md), [SC-036c](sc-036c.md), [SC-036d](sc-036d.md), [SC-036e](sc-036e.md)

**Summary**:
As the maintainer, I want the backlog index to hold only what the backlog script derives from the items, so that `set-status` and `toc` run here without refusing or losing anything.

**Description**:
The `backlog.py` script of the xxthunder-dev-skills plugin derives the table of contents in `docs/backlog/README.md` from the items: the items are the truth, the index only lists them. Run on this backlog (pulling SC-068 and SC-069 on 2026-10-22), it silently dropped what only the index held. Both pulls were done by hand instead.

Its fix (XAS-043 in xxthunder-agentic-skills) refuses such an index instead, so the script stops here until the index is derivable:

- **Annotated lines**: the four `### Superseded` lines carry `— replaced by [SC-040](sc-040.md) + [SC-036f](sc-036f.md)` after the link. The fix refuses them. Each of SC-036b to SC-036e already states the replacement in its own `> **Superseded (2026-07-10)** by …` note, so the annotation holds nothing the item lacks.
- **Legacy done markers**: `# [SC-013] COMPLETED - …` and `# [SC-021] ✅ DONE — …` (em dash) are not the `✅ DONE - ` the script knows. `check` names them, and the index would carry the marker into the title.

Titles in the index that differ from their item's heading (17 lines on 2026-10-22) are no problem: the script rewrites them to the heading, which is the truth (decided in XAS-043).

Raised on 2026-10-22.

**Scope Decisions**:
- **Drop the annotations, do not move them**: the replacement is already in each superseded item, so the index lines lose only their suffix.
- **Fix the markers in the items**: SC-013 and SC-021 get the heading prefix `✅ DONE - `.

**Acceptance Criteria**:
- [ ] The four `### Superseded` lines end with their link, with no text after it
- [ ] The headings of SC-013 and SC-021 start with `✅ DONE - `
- [ ] With a plugin version that carries XAS-043, `backlog.py check` reports nothing for this backlog, and `backlog.py toc` runs without an error
