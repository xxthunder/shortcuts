# [SC-073g] ADR headers in design-record's template format

**Status**: In Progress
**Priority**: Medium
**Component**: `docs/architecture/adr/`, `docs/architecture/README.md`
**Depends on**: XAS-044b in xxthunder-agentic-skills (the template with a colon heading)

**Summary**:
As the maintainer, I want the headers of the eight ADRs in `design-record`'s template format, so that the XAS-044b migration can turn them into needs for SC-073c.

**Description**:
The XAS-044b migration converts only headers in `design-record`'s template format and refuses any other. shortcuts' ADRs are consistent among themselves but differ from the template:

| | Template | shortcuts now |
|---|---|---|
| Heading | `# ADR-0005: Title` | `# ADR 0005: Title` |
| Status and date | `**Status**: Accepted` and `**Date**: 2026-10-19` | `**Status**: Accepted (2026-10-19)` |
| Item | `**Related**: [SC-067](...)` | `**Context item**: [SC-067](...)` |
| Supersede link | `**Supersedes**: [ADR-0005](...)` | `**Supersedes**: [ADR 0005](...)` |
| First line | the heading | `[← Back to Architecture](../README.md)`, then the heading |

The change is a correction that changes no meaning, the one kind of edit an accepted ADR allows besides its status line. This item is where the correction is recorded.

**Scope Decisions**:
- **Normalize, do not teach the migration** (author, 2026-11-08): the migration stays template-only; shortcuts adapts its headers.
- **Only the header block**: back-link, heading, status, date, item and supersede line; the body of every ADR stays as it is.
- **The ADR list in `docs/architecture/README.md`** follows the new headings (the agent's call, not discussed).
- **The back-link goes** (author, 2026-11-11): the migration reads the heading on the first line, and the template has no back-link. On the published pages the Sphinx sidebar leads back to the list.
- **A superseded ADR keeps its decision date**: ADR-0005's `**Date**` is 2026-10-19, the day it was accepted; the day it was superseded is ADR-0008's date (the agent's call, not discussed).

**Acceptance Criteria**:
- [x] All eight ADRs carry the template header: `# ADR-NNNN: Title`, `**Status**`, `**Date**` and `**Related**`, with the date and item they had
- [x] No ADR body changed (`git diff` touches only the header block)
- [x] The ADR list in `docs/architecture/README.md` shows the new headings
- [x] The documentation builds with Sphinx `-W`
