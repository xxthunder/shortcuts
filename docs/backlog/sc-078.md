# [SC-078] wsl-manager makes a distribution the default

**Status**: Open
**Priority**: Medium
**Component**: `tools/wsl-manager/wsl-manager.ps1`, `lib/wsl/commands.ps1`, `lib/wsl/ops.ps1`, `docs/wsl-manager.md`

**Summary**:
As a WSL user, I want wsl-manager to make a distribution the default one, so that `wsl` without `-d` opens the distribution I work in, without leaving wsl-manager for `wsl.exe --set-default`.

**Description**:
`list` already marks the default distribution with `*` (`IsDefault`), but wsl-manager cannot change it. Changing it takes `wsl.exe --set-default <name>` by hand.

Raised on 2026-10-28.

**Acceptance Criteria**:
- [ ] A command `set-default [<name>]` makes the named distribution the default; without a name it asks which one, like the other per-distribution commands
- [ ] The interactive menu offers it
- [ ] `list` shows the new default afterwards
- [ ] An unknown distribution name fails with a message and changes nothing
- [ ] Unit tests cover the command with `wsl.exe` mocked
- [ ] `docs/wsl-manager.md` and the script help name the command
