# [SC-071] Try Wox as a Keypirinha successor

**Status**: Open
**Priority**: Medium
**Component**: none (evaluation); outcome recorded in this item
**Related**: [SC-069](sc-069.md) (remove Flow Launcher), [SC-070](sc-070.md) (try PowerToys Command Palette)

**Summary**:
As a keyboard-driven Windows user, I want to try Wox in daily use, so that I know whether it can replace Keypirinha.

**Description**:
Keypirinha is the default launcher of this repository, and it is dormant: the last release is 2.26 from 2020-11-08, the core is closed source, and new issues such as a broken hotkey on Windows 11 get no answer. Flow Launcher was tried for a year and rejected (SC-069).

Wox is an open-source launcher that is actively developed again: release v2.4.7 came out on 2026-10-15. Scoop's `extras` bucket packages it as `wox` (version 2.4.7 on 2026-10-22).

What the current release offers, checked on 2026-11-06 against Wox v2.4.9 (2026-10-31) and its source:

- **Apps**: the app plugin indexes Start menu shortcuts and packaged apps, and takes own app directories.
- **`.url` files**: indexed as apps; `links/` can be added as an own app directory.
- **`.bat` with arguments**: the shell plugin runs commands, with `pwsh` among its interpreters.
- **Google**: the web search plugin.
- **Everything**: not used; Wox has its own file indexer (NTFS MFT and USN journal).
- **History**: results the author picked in the last 7 days score higher, more so for the same query.
- **PowerShell completion**: none; it would take an own plugin (Python or Node.js).
- **Speed**: no measurement found; only the trial can tell.

This item is a trial, not an integration. If Wox passes, a new item integrates it into the repository; if not, this item closes with the reason.

Raised on 2026-10-22.

**Scope Decisions**:
- **Trial before code**: nothing in the repository changes in this item. Installer, configuration and docs follow in a separate item, only after the trial passes.
- **Compared against Keypirinha**: the yardstick is Keypirinha as the author uses it today, not Flow Launcher.

**Acceptance Criteria**:
- [ ] Wox is installed from Scoop on the author's Windows machine and used as the daily launcher
- [ ] The item records whether Wox finds and launches everything the Start menu and Win+S find
- [ ] The item records whether Wox finds and opens the `.url` links from `links/` and from the private shortcuts
- [ ] The item records whether Wox runs the `.bat` wrappers of the tools with arguments, such as `wsl-manager` and `px-proxy`
- [ ] The item records whether Wox runs a Google search from the search box
- [ ] The item records whether Wox searches files through Everything, or how its own indexer compares with Everything
- [ ] The item records whether Wox puts what was launched before on top of the next search
- [ ] The item records whether Wox completes PowerShell parameters, built in or through an extension
- [ ] The item records how the hotkey and the search speed compare with Keypirinha
- [ ] The item records the author's verdict and its reason: replace Keypirinha, or reject
- [ ] On "replace", a follow-up item for the integration exists
