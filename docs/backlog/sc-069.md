# [SC-069] ✅ DONE - Remove Flow Launcher

**Status**: Done (2026-10-23)
**Priority**: Medium
**Component**: `tools/flow-launcher/`, `docs/runbooks/flow-launcher-setup.md`, `README.md`, `docs/architecture/workspace.dsl`, `docs/architecture/workspace.json`, `config/keypirinha/portable/Profile/User/Keypirinha.ini`
**Related**: [FEAT-003](feat-003.md) (added Flow Launcher as an optional tool), [SC-070](sc-070.md) (try PowerToys Command Palette), [SC-071](sc-071.md) (try Wox)

**Summary**:
As the maintainer, I want Flow Launcher gone from the repository, so that the repository offers no launcher that I have already rejected.

**Description**:
FEAT-003 added Flow Launcher as an optional launcher next to Keypirinha. The author used it for about a year and rejects it: it does not come close to Keypirinha. It stays an option only on paper, and its installer, plugin configuration, tests and runbook cost upkeep for nothing.

Keypirinha remains the default launcher. Its last release is 2.26 from 2020-11-08, and the core is closed source; the search for a maintained successor goes on in SC-070 and SC-071.

Raised on 2026-10-22.

**Scope Decisions**:
- **Remove, do not deprecate**: the tool, its tests and its runbook are deleted. No deprecation notice and no fallback.
- **The repository only**: uninstalling Flow Launcher from a machine (`scoop uninstall flow-launcher`) is the user's step, not a script.
- **Keypirinha takes over Alt+Space** (the author's exception, 2026-10-23): with Flow Launcher gone, `Alt+Space` is free. `hotkey_run` in `Keypirinha.ini` moves from `Win+Alt+Space` to `Alt+Space`, and every place that names the hotkey follows: the README, the skills and the catalog-refresh hints the install scripts print. `bin/install.ps1` copies the profile over the installed one, so a run of it brings the new hotkey to a machine.

**Acceptance Criteria**:
- [x] `tools/flow-launcher/` is deleted, scripts, wrappers and tests included
- [x] `docs/runbooks/flow-launcher-setup.md` is deleted
- [x] `README.md` no longer lists Flow Launcher
- [x] `docs/architecture/workspace.dsl` has no Flow Launcher setup container, no Flow Launcher system and none of their relationships, and `workspace.json` matches it
- [x] `git grep -i "flow.launcher"` finds nothing outside `docs/backlog/`
- [x] `Keypirinha.ini` sets `hotkey_run = Alt+Space`, and `git grep "Win+Alt+Space"` finds nothing outside `docs/backlog/`
- [x] All existing tests continue to pass, and PSScriptAnalyzer is clean

**UAT Procedure** (on the Windows machine, with the feature branch checked out):

1. [x] Run `scoop uninstall flow-launcher`. Expect Flow Launcher gone and the Keypirinha hotkey to open Keypirinha.
2. [x] Run `bin/install.ps1`. Expect it to finish without mentioning Flow Launcher.
3. [x] Press `Alt+Space`. Expect Keypirinha to open.
