# [SC-070] ✅ DONE - Try PowerToys Command Palette as a Keypirinha successor

**Status**: Done (2026-11-08)
**Priority**: Medium
**Component**: none (evaluation); outcome recorded in this item
**Related**: [SC-069](sc-069.md) (remove Flow Launcher), [SC-071](sc-071.md) (try Wox)

**Summary**:
As a keyboard-driven Windows user, I want to try PowerToys Command Palette in daily use, so that I know whether it can replace Keypirinha.

**Description**:
Keypirinha is the default launcher of this repository, and it is dormant: the last release is 2.26 from 2020-11-08, the core is closed source, and new issues such as a broken hotkey on Windows 11 get no answer. Flow Launcher was tried for a year and rejected (SC-069).

PowerToys Command Palette is Microsoft's launcher inside PowerToys and is actively developed. Scoop's `extras` bucket packages PowerToys as `powertoys` (version 0.102.2933.0 on 2026-10-22).

What the current release offers, checked on 2026-11-06 against PowerToys 0.102.3101.0 (Command Palette last changed in 0.102.2933.0) and its source:

- **Apps**: All Apps indexes the Start menu, the desktop, `PATH` and packaged apps.
- **`.url` files**: indexed by default (`ProgramSuffixes` includes `url`), but only from those sources; there is no setting for an extra folder. `links/` needs a link from the Start menu or a Bookmark per link.
- **`.bat` with arguments**: `>` followed by the command; Bookmarks can prompt for `{query}` placeholders.
- **Google**: `??` followed by the query; the search engine is selectable since 0.97.
- **Everything**: not built in; the community extension [EverythingCommandPalette](https://github.com/lin-ycv/EverythingCommandPalette) adds it (Scoop, WinGet).
- **History**: since the ranking rework of 2026-08 (0.101), results are ranked by recency and frequency (3-day half-life, up to 500 entries, persisted); earlier builds did not persist history.
- **PowerShell completion**: none; it would take an own extension (C#).
- **Speed**: no measurement found; only the trial can tell.

Trial notes:

- **2026-11-07, junctions**: Command Palette does not follow junctions in the Start menu. Its scan skips every reparse point by design (`Win32Program.ProgramPaths`, `AttributesToSkip = ... ReparsePoint`), so junctions from the Start menu to `~\shortcuts` and `~\shortcuts_private` add nothing.
- **2026-11-07, shortcut to a `.bat`**: a real `.lnk` in the Start menu pointing to `wsl-manager.bat` is found, in Search apps and in the main search. It appears only after Command Palette restarts; neither `reload` nor waiting picked it up.
- **2026-11-07, restart**: after switching Command Palette off and on in PowerToys, the hotkey works only once its tray icon appears, which takes a while; Keypirinha is ready almost at once.
- **2026-11-07, no folder catalog**: Installed apps scans only the Start menu, the desktop and `PATH`, with no setting for an own folder; `PATH` entries appear only on an exact name. No community extension for an own folder was found on the web. Without an own extension, the scripts of `~\shortcuts` reach the top-level search only as generated `.lnk` files in the Start menu, refreshed by a restart; the Everything extension finds them, but outside the history ranking. An own extension that catalogs `~\shortcuts\**` and `~\shortcuts_private\**` as top-level commands is the open option.

Outcome of the trial (2026-11-08):

- **Apps**: found and launched from the main search, also Start menu apps; nothing missing was noticed.
- **`.url` links and `.bat` wrappers**: not found from `links/`, `~\shortcuts` or `~\shortcuts_private` (no folder catalog, junctions skipped); a `.lnk` in the Start menu to a `.bat` works after a restart. The folder extension CmdPal.Extension.Folders (CPF-002) closes the gap. Arguments for a `.bat` were not tried; by the source, `>` with the full path or a Bookmark with `{query}` takes them.
- **Web search**: the fallback "Search the web" offers the query in the default browser (Brave on the author's machine); Google as the engine was not tried.
- **Everything, history ranking, PowerShell completion, search speed**: not tried in the trial. By the source: Everything through the community extension, history ranking since 0.101, no PowerShell completion.
- **Hotkey**: after PowerToys starts, the hotkey works only once the tray icon is there, which takes a while; Keypirinha is ready almost at once.
- **Verdict** (the author, 2026-11-08): replace Keypirinha. Command Palette is installed by [SC-086](sc-086.md) as the launcher on `Alt+Space`, and its UAT passed on 2026-11-08. Reason, as the trial shows it: Keypirinha is dormant, Command Palette is actively developed and covers apps, web search and history ranking; its one gap for this repository, the shortcuts folders, is being closed by CPF-002.

This item is a trial, not an integration. If Command Palette passes, a new item integrates it into the repository; if not, this item closes with the reason.

Raised on 2026-10-22.
