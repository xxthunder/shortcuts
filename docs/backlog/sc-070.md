# [SC-070] Try PowerToys Command Palette as a Keypirinha successor

**Status**: Open
**Priority**: Medium
**Component**: none (evaluation); outcome recorded in this item
**Related**: [SC-069](sc-069.md) (remove Flow Launcher), [SC-071](sc-071.md) (try Wox)

**Summary**:
As a keyboard-driven Windows user, I want to try PowerToys Command Palette in daily use, so that I know whether it can replace Keypirinha.

**Description**:
Keypirinha is the default launcher of this repository, and it is dormant: the last release is 2.26 from 2020-11-08, the core is closed source, and new issues such as a broken hotkey on Windows 11 get no answer. Flow Launcher was tried for a year and rejected (SC-069).

PowerToys Command Palette is Microsoft's launcher inside PowerToys and is actively developed. Scoop's `extras` bucket packages PowerToys as `powertoys` (version 0.102.2933.0 on 2026-10-22).

This item is a trial, not an integration. If Command Palette passes, a new item integrates it into the repository; if not, this item closes with the reason.

Raised on 2026-10-22.

**Scope Decisions**:
- **Trial before code**: nothing in the repository changes in this item. Installer, configuration and docs follow in a separate item, only after the trial passes.
- **Compared against Keypirinha**: the yardstick is Keypirinha as the author uses it today, not Flow Launcher.

**Acceptance Criteria**:
- [ ] PowerToys with Command Palette is installed from Scoop on the author's Windows machine and used as the daily launcher
- [ ] The item records whether Command Palette finds and opens the `.url` links from `links/` and from the private shortcuts
- [ ] The item records whether Command Palette runs the `.bat` wrappers of the tools, such as `wsl-manager` and `px-proxy`
- [ ] The item records how the hotkey and the search speed compare with Keypirinha
- [ ] The item records the author's verdict and its reason: replace Keypirinha, or reject
- [ ] On "replace", a follow-up item for the integration exists
