# [SC-086] Install PowerToys Command Palette alongside Keypirinha

**Status**: In Progress
**Priority**: High
**Component**: `scoop_mandatory.json`, `bin/install.ps1`, `README.md`, `docs/architecture/workspace.dsl`, `docs/architecture/workspace.json`
**Related**: [SC-070](sc-070.md) (Command Palette trial), CmdPal.Extension.Folders [CPF-002](https://github.com/xxthunder/CmdPal.Extension.Folders/blob/develop/docs/backlog/cpf-002.md) (extension that catalogs the shortcuts folders)

**Summary**:
As a keyboard-driven Windows user, I want the install to set up PowerToys Command Palette next to Keypirinha, so that I can use both every day and test Command Palette thoroughly before deciding on a successor.

**Description**:
The trial SC-070 shows that Command Palette covers apps, `.url` files in the Start menu, Google, Everything (through an extension) and history ranking, but cannot catalog the shortcuts folders without an extension of its own; that extension is being built in CmdPal.Extension.Folders (CPF-002). To test Command Palette in daily use, the repository installs it next to Keypirinha instead of asking for a manual setup on every machine.

Keypirinha stays the default launcher on `Alt+Space`. Command Palette keeps its default hotkey `Win+Alt+Space`, so the two never compete for a key.

Raised on 2026-11-07.

**Scope Decisions**:
- **Integration before the trial closes** (the author's exception, 2026-11-07): SC-070 planned the integration only after a passing trial. The author integrates now, in parallel to Keypirinha, to test Command Palette more thoroughly; SC-070 stays open for the verdict.
- **Parallel, not replacing**: Keypirinha, its profile and its hotkey stay as they are.
- **Default hotkey**: Command Palette is not configured; `Win+Alt+Space` is its default.
- **The folder extension is not part of this item**: installing CmdPal.Extension.Folders follows once CPF-002 delivers it.

**Acceptance Criteria**:
- [ ] `scoop_mandatory.json` installs `extras/powertoys`
- [ ] `bin/install.ps1` installs PowerToys on a fresh machine and leaves the Keypirinha setup unchanged
- [ ] `README.md` names Command Palette next to Keypirinha, with its hotkey `Win+Alt+Space`
- [ ] `docs/architecture/workspace.dsl` has Command Palette as an external system next to Keypirinha, and `workspace.json` matches it
- [ ] Unit tests and PSScriptAnalyzer pass

**UAT**:
1. [ ] Run `bin/install.ps1` on the author's machine. Expect PowerToys installed, Keypirinha still on `Alt+Space`, and Command Palette opening on `Win+Alt+Space`.
