# [SC-036f] ✅ DONE - Auto proxy setup detects a running Windows px

**Status**: Done (2026-07-16)
**Priority**: High
**Component**: `lib/wsl/proxy.ps1`, `lib/utils/utils.ps1`, `tools/proxy/setProxy.ps1`, `lib/wsl/scripts/setup-proxy-negotiate.sh` (removed), `docs/wsl-manager.md`
**Depends on**: [SC-036a](sc-036a.md), [SC-040](sc-040.md)
**Parent**: [SC-036](sc-036.md)

**Summary**:
As a developer, I want `wsl-manager setup-proxy` in Auto mode to detect a running Windows-side px proxy ([SC-040](sc-040.md)) and let me point WSL at it — so my distro reaches the internet with no credentials stored anywhere — falling back to the PAC-detected corporate proxy when I prefer it or px is not running.

**Description**:
`Install-WslProxy` already dot-sources `tools/proxy/setProxy.ps1`, so it can reuse `Test-PxProxyAvailable` (added in SC-040) to probe `http://127.0.0.1:3128`. In Auto mode, when px is running, the user chooses between:

- **Px** — WSL targets `http://127.0.0.1:3128`. px authenticates to the corporate proxy via SSPI on the Windows host; WSL reaches it via mirrored networking. No credentials enter WSL.
- **Pac** — the existing PAC-resolved corporate-proxy flow (confirm the URL, then pick an auth method).

The Basic/Negotiate auth prompt is replaced by **Anonymous / Basic** (the in-WSL Kerberos Negotiate path is superseded — see [SC-036](sc-036.md)). Basic is the opt-in to credentials and prefills the Windows username; Anonymous embeds none. The obsolete `setup-proxy-negotiate.sh` and its exit-code-10 dispatch are removed.

**Scope Decisions**:
- **px detection only in Auto**: Manual mode stays an explicit `host:port` entry (no probing); Remove is unchanged. The px-vs-PAC choice belongs to "figure it out for me".
- **`Get-UserChoice` for the prompts**: a shared multi-option helper (ported from the superseded SC-036b branch) backs both the px-vs-PAC and Anonymous/Basic prompts, with an Enter default and CI/test short-circuit.
- **px path is credential-less**: choosing Px sets auth mode to `anonymous` and skips the auth prompt and credential entry entirely — px owns authentication on the host.
- **Basic default for the corporate proxy**: when a PAC/manual corporate URL is used, the auth prompt defaults to Basic (corporate proxies usually require auth), with Anonymous as the explicit opt-out.
- **Remove the Negotiate script**: `setup-proxy-negotiate.sh` is deleted rather than left as a stub, since the approach it stubbed is abandoned.

**Acceptance Criteria**:

- [x] Choosing Px targets `http://127.0.0.1:3128` with no credentials and no auth/credential prompt
- [x] Choosing Pac falls through to the existing PAC confirm + auth flow
