# [SC-090] update-scoop's tests assert every clause of its requirements

**Status**: Open
**Priority**: Low
**Component**: `lib/scoop/scoop.Tests.ps1`
**Depends on**: [SC-073h](sc-073h.md)

**Summary**:
As the maintainer, I want every clause of update-scoop's requirements asserted by a test, so that a requirement shown as passed on the traces page is passed in every part.

**Description**:
SC-073h traced update-scoop's requirements to the `It`s that existed, without new test logic. Some `It`s test only part of the requirement they trace to, so the traces page shows the requirement as passed while a clause of it is asserted by nothing (final review of SC-073h, 2026-11-15):

- `REQ_SCOOP_PRESENT`: "ends without touching anything" (no Scoop command runs after the message).
- `REQ_SCOOP_LIST`: the numbering and the installed and latest versions of each listed app.
- `REQ_SCOOP_SELECT`: "With no updatable apps, only `R` and `Q` are offered" (the prompt text).
- `REQ_SCOOP_REFRESH_START`: "a failure is shown and the helper goes on".

**Acceptance Criteria**:
- [ ] Each clause above is asserted by a Pester `It` with a test marker that `:tests:` its requirement, and the `It` fails when the clause is broken
- [ ] No behaviour of update-scoop changes
