# [SC-066b] wsl-manager turns automount and interop off for a distribution

**Status**: Open
**Priority**: Medium
**Component**: `lib/wsl/wsl-conf.ps1`, `lib/wsl/commands.ps1`, `lib/wsl/exec.ps1`, `lib/wsl/ssh.ps1`, `docs/wsl-manager.md`
**Depends on**: [SC-066a](sc-066a.md)

**Summary**:
As a developer, I want wsl-manager to turn `automount` and `interop` off for a distribution an agent works in, so that the distribution is a boundary between the agent and Windows.

**Description**:
The boundary part of [SC-066](sc-066.md). `Set-WslConf` can write any section of `wsl.conf`, but no command turns `automount` and `interop` off; the example in its help turns `interop` on, and `repair-interop` turns it back on.

wsl-manager itself needs `/mnt/c`: `Invoke-WslScript` turns the Windows path of every script into a `/mnt/<drive>` path (`lib/wsl/exec.ps1`), and the SSH config sync reads the Windows `.ssh` folder the same way (`lib/wsl/ssh.ps1`). With `automount` off, `setup-ca`, `setup-proxy`, `sync-ssh-config` and `setup-dev-stack` no longer work in that distribution.

**Scope Decisions**:
- **Only on request** (decided 2026-11-27): the switch is for a distribution an agent works in. Other distributions keep `automount` and `interop` on.

**Open Questions**:
- How does wsl-manager work in a distribution with `automount` off? Option a: the switch is the last step, and every later wsl-manager step needs `automount` back on first. Option b: wsl-manager sends scripts over stdin (`wsl -d <name> -- bash -s < script`) and needs no `/mnt/c`; this is a refactor of `Invoke-WslScript` and the SSH config sync.
- What does `repair-interop` do in a distribution with `interop` off on purpose?

**Acceptance Criteria**:
- [ ] A wsl-manager command turns `automount` and `interop` off for one distribution
- [ ] After the switch, `/mnt/c` is absent and a Windows program does not start from the distribution
- [ ] wsl-manager steps that need `/mnt/c` work in that distribution, or stop with a message that names the switch
- [ ] `docs/wsl-manager.md` describes the switch and what it turns off
