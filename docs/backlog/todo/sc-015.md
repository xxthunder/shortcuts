# [SC-015] Reorganize project structure: separate tools from libraries

**Status**: Open
**Priority**: Medium
**Component**: `tools/pslib/`

**Summary**:
As a developer, I want a clear separation between reusable libraries (`lib/`) and executable tools (`tools/`) so that the project structure reflects the actual dependency direction.

**Description**:
Currently, wsl-manager (a tool) lives inside `tools/pslib/wsl/` and the utility library lives inside `tools/pslib/utils/`. This conflates two different concerns: libraries are reusable modules, while wsl-manager is a standalone tool that depends on them.

Target structure:
```
lib/
  install/
    install-npm-global.ps1    # Reusable npm-global installer (no .bat wrapper)
  utils/
    utils.ps1                 # Reusable PowerShell utilities
    utils.Tests.ps1
    utils.Integration.Tests.ps1
  wsl/
    scripts/                  # Shell scripts used by WSL library functions
    core.ps1                  # WSL library modules
    docker.ps1
    exec.ps1
    install.ps1
    ops.ps1
    podman.ps1
    proxy.ps1
    user.ps1
    commands.ps1
    wsl.ps1                   # WSL library entry point (dot-sources modules)
    *.Tests.ps1               # Unit tests for library modules
tools/
  wsl-manager/
    wsl-manager.ps1           # Tool entry point
    wsl-manager.bat           # Batch wrapper
    *.Integration.Tests.ps1   # Integration tests
```

The `tools/pslib/` directory is eliminated entirely. The `AGENTS.md` / `CLAUDE.md` files currently in `tools/pslib/` should be reviewed and merged into the appropriate new locations.

Impact analysis: ~216 path references across ~42 files (source code, docs, skills, backlog items, CI config) need updating. This includes dot-source paths in PowerShell scripts, documentation paths, skill references, and CI pipeline paths.

**Acceptance Criteria**:
- [ ] `tools/pslib/utils/` moved to `lib/utils/`
- [ ] `tools/pslib/wsl/lib/` contents (modules, scripts, unit tests) moved to `lib/wsl/`
- [ ] `tools/pslib/wsl/` tool files (entry point, bat wrapper, integration tests) moved to `tools/wsl-manager/`
- [ ] `tools/install/install-npm-global.ps1` moved to `lib/install/install-npm-global.ps1`
- [ ] `tools/install/install-npm-global.bat` removed (redundant; pwsh is required anyway)
- [ ] `tools/pslib/` directory eliminated
- [ ] `tools/install/` directory eliminated
- [ ] All internal dot-source paths updated (e.g., `utils.ps1` sourcing)
- [ ] All documentation paths updated (`docs/wsl-manager.md`, `README.md`, etc.)
- [ ] All skill references updated (`.claude/skills/`)
- [ ] CI pipeline paths updated if applicable
- [ ] Keypirinha/Flow Launcher shortcuts updated
- [ ] `.bat` wrapper paths updated
- [ ] All existing tests continue to pass
