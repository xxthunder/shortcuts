# [SC-013] Fix and enhance documentation

**Status**: Open
**Priority**: Medium
**Component**: `docs/wsl-manager.md`

**Summary**:
As a user, I want the documentation to provide guidance for both interactive and CLI execution so that I can follow the walkthrough regardless of my preferred workflow.

**Description**:
The DevContainer walkthrough in `docs/wsl-manager.md` currently shows CLI commands for each step but only has a brief tip at the top mentioning the interactive menu. Users following the guide interactively may not know which menu option corresponds to each step, or what prompts to expect. The documentation should clearly show both paths for each step.

**Acceptance Criteria**:
- [ ] The DevContainer walkthrough steps provide guidance for interactive and CLI execution
- [ ] All existing tests continue to pass
