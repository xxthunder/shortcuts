# [SC-081] Setup CA with the default URL misses the intranet root CA

**Status**: Open
**Priority**: High
**Component**: `lib/wsl/commands.ps1` (`Read-UrlRootCertificate`), `lib/wsl/ca.ps1`, `docs/wsl-manager.md`

**Summary**:
As a developer setting up a WSL distribution behind a TLS-inspecting proxy, I want "Setup CA certificates" to install every root CA I need with its default, so that both internet and intranet hosts work in the distribution without a second run.

**Description**:
Found on 2026-10-22 in the UAT of a downstream fork that vendors this repository as a subtree.

Auto mode offers `https://www.google.com` as the default URL (`$script:WslCaDefaultUrl` in `lib/wsl/ca.ps1`). Pressing Enter installs only the root of the TLS-inspection chain, the proxy's CA. The company's intranet root CA is then missing, and TLS to an intranet host such as the company's git server fails in the distribution with "self-signed certificate in certificate chain". Running Setup CA again with the intranet URL fixed it.

`Read-UrlRootCertificate` already loops and accepts more URLs ("intranet sites with their own PKI can follow"), but nothing tells the user that the default covers only the proxy, and a test with an internet host alone does not notice the gap.

**Open Questions**:
- How does the intranet URL reach the default without naming a company in this repository: a setting in `config/`, an environment variable, or a parameter the downstream fork sets?
- Should the prompt say that Enter installs only the proxy's CA and ask for intranet hosts next?
- Should `docs/wsl-manager.md` tell users to test an intranet host as well, e.g. with `git clone` or `curl`?

**Acceptance Criteria**:
- [ ] With the default answer, Setup CA installs the proxy's CA and the configured intranet root CA
- [ ] Without a configured intranet URL, the prompt says that the default covers only the proxy's CA
- [ ] `docs/wsl-manager.md` says how to set the intranet URL and how to check both kinds of host
- [ ] Unit tests cover the default with and without a configured intranet URL
- [ ] All existing tests continue to pass
