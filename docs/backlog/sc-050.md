# [SC-050] ✅ DONE - Trim AGENTS.md duplication, point to powershell-dev skill

**Status**: Done (2026-07-29)
**Priority**: Low
**Component**: `AGENTS.md`

**Summary**:
As a contributor relying on `AGENTS.md` for always-loaded agent guidance, I want the file free of content that duplicates the codebase or an existing skill, so that every session pays for less redundant context and the `powershell-dev` skill (previously never invoked) becomes the single source of truth for PowerShell development workflow.

**Description**:
A `/doctor` context audit found that `AGENTS.md`'s "PowerShell Implementation Guidelines" section (#1, #2, #4, #7, #9 plus the "When Implementing/Modifying Functions" and "Mandatory Pre-Commit Checks" workflow subsections) duplicated the `.claude/skills/powershell-dev/SKILL.md` skill almost line-for-line: script structure templates, error handling setup, `.bat` wrapper creation, TDD workflow, and the pre-commit checklist. The audit's usage data showed `powershell-dev` had zero recorded invocations across the scan window, consistent with the model never needing to reach for the skill since the same content was already always-loaded.

Separately, the file had a literal duplicate "Directory Structure" list (a shorter copy of the one given earlier in the same file) and a `Write-Status`/`Write-Success`/`Write-ErrorMsg` example whose functions already exist verbatim in `lib/utils/utils.ps1:475-489`.

**Scope Decisions**:
- **Migrate, don't just delete**: sections that duplicated the `powershell-dev` skill were collapsed into a one-line pointer to that skill, not removed outright, since the skill already covers the same ground.
- **Keep all safety-critical and non-standard content in the root file**: the UTF-8 BOM requirement, the per-filetype line-ending rules, the bash/PowerShell piping pitfall, and the "don't use `Set-StrictMode` in dot-sourced files" gotcha stayed inline, since these apply to any agent action in the repo (not just "writing a new PS script") and a lazily-loaded skill might not be in context when they matter.
- **No plugin/skill usage-count changes were part of this item**: the `/doctor` run also disabled several unused plugins and project skills via local Claude Code settings, but that is IDE/agent configuration, not a repo change, and is out of scope for this backlog item.

**Acceptance Criteria**:
- [x] Duplicate "Directory Structure" list removed
- [x] `Write-Status`/`Write-Success`/`Write-ErrorMsg` example replaced with a pointer to `lib/utils/utils.ps1`
- [x] Generic `Join-Path`/`Test-Path` example replaced with a one-line reminder
- [x] Sections #1, #2, #4, #7, #9 templates and the "When Implementing/Modifying Functions" workflow detail collapsed into pointers to the `powershell-dev` skill
- [x] "Mandatory Pre-Commit Checks" trimmed to drop the duplicate command examples (already given under "Testing Requirements") while keeping the "Never commit if" prohibitions
- [x] BOM, line-ending, bash/pwsh piping, and dot-sourcing strict-mode rules remain in `AGENTS.md` unchanged
- [x] A stray leftover code-fence bug (pre-existing in the removed section) is fixed
- [x] `AGENTS.md` remains valid CRLF, no unpaired code fences
