# [SC-076] Short test result IDs, and a Test results page that fits and stays current

**Status**: Open
**Priority**: Medium
**Component**: `ubproject.toml`, `docs/_static/shortcuts.css`, `docs/test-results.md`
**Related**: [SC-073d](sc-073d.md)

**Summary**:
As a reader of the documentation, I want the test results to carry short IDs and the Test results page to stay within the window when a box is expanded, so that I can read every result without scrolling sideways.

**Description**:
SC-073d switched on `deterministic_case_ids`, so that a result's ID stays the same when its test fails differently. The IDs have the form `{type}__{Classname__Casename}_{hash}`, such as `testcase__ps1__Remove_Path_When_path_does_not_exist_Should_not_attempt_to_delete_non_existent_path_ppqza`. Pester's class name is the test file's path, and the readable part keeps only what follows its last dot, `ps1`, which says nothing. The default IDs are short (`TESTFILE_PESTER_8FE_F0D6F`) but hash the need's content, which holds the failure text.

On the Test results page, expanding a test file or test suite box makes the page wider than the window, and it cannot be scrolled to the right. SC-073d measured the page with the boxes collapsed only.

A local incremental build does not notice when `test/out/junit.xml` changes or disappears: it keeps the results it read before, and the schema gate then judges stale results (seen on 2026-10-27, after renamed `It`s). A fresh build (`-E`), as CI always runs, reads the report anew.

Raised on 2026-10-27.

**Scope Decisions**:
- **IDs stay stable across failures**: whatever replaces the current scheme keeps a result's ID when only its failure text changes.

**Acceptance Criteria**:
- [ ] A result's ID is short enough to read, and unchanged when only the failure text of its test changes
- [ ] With every box on Test results expanded, the page is no wider than the window, in light and dark mode
- [ ] Each px-proxy result still links its test
- [ ] A local build after a new test run shows the new results without a fresh build
